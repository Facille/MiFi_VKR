# Заметки для ВКР

## Формулировка результата

Разработана гибридная методика анализа контекста программного кода для интеллектуального автодополнения. Система работает на двух уровнях: token-level completion для недописанного токена и block-level prediction для следующего блока кода. Методика объединяет статический синтаксический анализ, токенизацию, lightweight vector embeddings и статистическое ранжирование кандидатов.

## Научно-практическая новизна

- контекст рассматривается не только как строковый префикс, но как набор структурных признаков;
- отдельно рассматриваются задачи token completion и block prediction;
- блоки кода приводятся к абстрактным сигнатурам, что позволяет оценивать качество не только по точному текстовому совпадению;
- ранжирование объединяет частотные, структурные, токеновые и семантические признаки;
- система допускает локальное обучение на кодовой базе пользователя.

## Что показывать комиссии

1. Обучение модели на папке `examples/train`.
2. Token autocomplete для `examples/token_snippet.py`.
3. Block prediction для `examples/incomplete_snippet.py`.
4. Оценку на held-out папке `examples/test`.
5. Отчеты `evaluation_report.json` и `evaluation_report.md`.
6. Web UI через команду `serve`.
7. Код модулей `context_analyzer.py`, `token_predictor.py`, `block_predictor.py`, `embeddings.py`, `evaluation.py`.

## Почему это не просто набор правил

Шаблоны используются как baseline и fallback. Основной список кандидатов для block prediction берется из обучающего корпуса, а итоговый рейтинг зависит от статистики переходов, области видимости, токенового пересечения, специальных контекстных признаков и embedding similarity. Token completion использует текущий префикс токена и символы, извлеченные из контекста.

## Что честно указать как ограничение

В проекте используется легкая TF-IDF-векторизация вместо тяжелой нейросетевой модели. Это сделано для воспроизводимости без внешних зависимостей. В разделе дальнейшего развития можно указать замену embedding-модуля на CodeBERT, CodeT5 или другую HuggingFace-модель, а также разработку полноценного расширения VS Code поверх локального API.

- template baseline: 0.3056;
- token completion top-1 accuracy: 0.9583;
- token completion top-5 accuracy: 1.0;
